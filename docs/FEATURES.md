# Dalỏ Multi v1.3 Features

## Native UI foundation
- shared semantic design tokens for light/dark appearance
- control-center overview with live system status
- consistent flat surfaces with restrained elevation
- VoiceOver labels for key icon actions
- Reduce Motion-aware transitions
- labeled clone creation fields and actionable empty states

## Daily workflow
- dashboard cards or compact rows
- favorites, notes, search and sort
- command palette
- menu bar controls
- keyboard shortcuts

## Workspaces
- launch groups
- preferred Split/Grid/Cascade layout
- save and restore current window positions

Window control requires macOS Accessibility permission. Dalỏ only uses it to move/resize windows.

## Updates and repair
- version mismatch detection
- bulk update stopped clones
- safe rebuild from official Zalo source
- old app bundle retained until new bundle swap succeeds
- health dashboard and diagnostics

## Backup
Configuration export/import covers Dalỏ metadata/preferences, not Zalo credentials, messages or login sessions.
